# The [default] extra is not optional in practice:
#   mutagen      - required to embed cover art into opus/flac/ogg, and yt-dlp
#                  raises rather than skipping when it is missing
#   yt-dlp-ejs   - the JavaScript that solves YouTube's signature challenges
# A bare `pip install yt-dlp` installs neither.
yt-dlp[default]>=2025.11.12

# simplest way to get one is to let pip provide it:
#
#     pip install "yt-dlp[deno]"
#
